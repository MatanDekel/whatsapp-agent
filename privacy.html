Privacy Policy – Nuviko Agent

Nuviko Agent is a private, personal assistant used only by its owner. It is not offered to the public.

What data is processed

Messages sent to the assistant's WhatsApp number, calendar events synced from the owner's iPhone, and notes, tasks and reminders the owner creates.

How it is used

Data is used only to answer the owner's messages and send reminders and summaries. Message content is processed by Anthropic's Claude API to generate replies. Data is stored in a private database (Upstash) and is never sold or shared with third parties for marketing.

Google user data

If the owner connects Google Calendar, the assistant reads upcoming calendar events (titles, times and locations) to answer questions and send reminders, and creates events only when the owner asks. Google tokens and a short-term copy of upcoming events are stored in the assistant's private database. Google user data is not shared with third parties, not used for advertising, and not used to train AI models. The assistant's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The owner can disconnect at any time from their Google Account (Security → Third-party apps), which revokes access.

Retention and deletion

Conversation history is limited to recent messages. The owner can delete history at any time by sending /reset. To request deletion of any data, contact the owner at mdekel16@gmail.com.
