Privacy Policy – Nuviko Agent

Nuviko Agent is a private, personal assistant used only by its owner. It is not offered to the public.

What data is processed

Messages sent to the assistant's WhatsApp number, calendar events synced from the owner's iPhone, and notes, tasks and reminders the owner creates.

How it is used

Data is used only to answer the owner's messages and send reminders and summaries. Message content is processed by Anthropic's Claude API to generate replies. Data is stored in a private database (Upstash) and is never sold or shared with third parties for marketing.

Retention and deletion

Conversation history is limited to recent messages. The owner can delete history at any time by sending /reset. To request deletion of any data, contact the owner at mdekel16@gmail.com.
